# Savanna mammals and Nile monitor: source audit

Reviewed on 2026-09-20 for `src/content/savanna-mammals.ts` under parent Kanban `t_07f3901b`, run 89. This is an editorial source check, not a scientific-review signoff. The batch contains seven mammals and one reptile; Nile monitor is explicitly classified as Reptile in the data.

## Method

Browsed the institutional pages below and checked each linked Wikipedia species page. The original child-facing prose uses institutional sources; Wikipedia is supplementary reading, not the authority for quiz answers. Every statistic and question carries resolvable source IDs, and the description cites its supporting sources. Summary and habitat claims use the same sources as the corresponding description and statistics. Questions appear in spot / understand / connect order and each has exactly three choices.

Measurements are approximate biological ranges, not model scale specifications. Length includes the tail only where stated. Records and population-specific estimates are not presented as typical ages. Unknown means the selected sources do not establish a dependable figure for that context. Historical conservation categories and unverified population counts were intentionally not copied.

## Model review cues

These are identification targets, not claims that generated assets have passed anatomical review.

- Aardvark: arched torso, sparse coat, long narrow snout, tubular ears, digging claws, tapered thick tail.
- Bat-eared fox: outsized ears, dark lower legs and ear backs, small fox body, bushy tail.
- Banded mongoose: short legs, elongated body, dark cross-bands from mid-back toward the tail.
- Meerkat: slender mongoose proportions, dark eye patches, pointed muzzle, thin tail; avoid cat anatomy.
- Olive baboon: long muzzle, quadrupedal stance, grey-green coat; a mature male has shoulder hair and a larger body.
- Vervet: black face, pale facial border, long slim tail, grasping hands and feet; avoid baboon muzzle proportions.
- Savanna buffalo: stocky bovine, curved horns, mature male horn boss; not a North American bison hump.
- Nile monitor: long scaled lizard with clawed legs, spotted/banded coat and swimming tail; not crocodile body proportions.
