# Adult standing height and weight: 32 safari species

Reviewed 21 September 2026. This is the **current field-notebook handoff**. Earlier sex-specific evidence is preserved in [story](size-story.md), [small-life](size-small-life.md), and [other expansion](size-expansion.md) notes; the old [sex-specific CSV](animal-adult-size-ranges.csv) is supporting research, not an import file for the requested height bar.

**Standing height** is level ground to the top of the adult head in an ordinary resting stance, in metres. Do not substitute shoulder height, body length, wingspan, horn or ear tips, or an asset's rendered size. “Not established” is a missing value, never zero. The three existing bird heights in `src/content` are retained. Three more bird sources publish overall/standing height. None of these six bird sources specifies the exact endpoint for crown, crest or casque; verify that before calibrating a precise picture bar.

**Adult weight** is a source-published adult or typical-species live-body-mass range in kilograms. A pooled outer envelope combines documented female and male ranges where available. It is not a universal biological limit. **†** means the institution's species-size guide does not explicitly say that every weight in its interval came from an adult sample; treat it as a broad guide. “H” and “W” in the Sources column mark height and weight evidence, including sources that show only an unsuitable alternate dimension.

## Notebook use

Only six bird rows have a published overall/standing-height interval. None of the mammals, rodents, insects or reptile has a verified ground-to-top-of-head **range** in these sources. The bird values can guide broad scale, but the crown/casque/crest endpoint needs checking against the posed artwork before a precise photo bar is shown. For other animals, let the student record an estimate without presenting an authoritative answer. Preserve “not established” as blank/null, never `0`.

The game's **northern giraffe** label conflicts with its Tarangire-inspired setting: [Giraffe Conservation Foundation identifies Masai giraffe there](https://giraffeconservation.org/wp-content/uploads/2019/04/GCF-Tanzanias-Giraffe-Poster-2022-LR.pdf). The Rothschild/Nubian weight above is only a northern-form reference; reassess it if the encounter changes to Masai giraffe.
