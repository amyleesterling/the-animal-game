# Animal image references

These are the original generated PNG references used to guide Meshy Image-to-3D. There are **32 animal images for 28 species**: three revised story animals, 25 expansion animals, and four later attempts for three of those expansion animals. The vehicle image is included separately below. The images are already tracked in this GitHub folder; this index makes the complete set and the preferred revisions easy to find.

For the height scale bar, **do not measure pixels in these pictures**. They are synthetic, perspective studio views with no calibrated length. Use researched species measurements and state what the bar means (shoulder height, standing height, body length, or wingspan). The animal profiles and source notes are in [`src/content`](../../src/content) and [`docs/research`](../../docs/research). The reference prompts are kept beside each image batch in `prompts.json`.
